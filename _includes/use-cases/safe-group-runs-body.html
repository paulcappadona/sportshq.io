{{ sg.faq1_q | default: "How does Sports HQ help me organise a safer group run?" }}

{{ sg.faq1_a | default: "Create an event with the people you already know and trust, mark it private if you'd rather keep it just between you, propose a time and route for your next run, and see in real time who has confirmed before you head out." }}

{{ sg.faq2_q | default: "Can I mark my running event as private?" }}

{{ sg.faq2_a | default: "Yes. Events are public by default, but you can mark yours private at any time so only the members you invite can see or join." }}

{{ sg.faq3_q | default: "What happens if nobody confirms?" }}

{{ sg.faq3_a | default: "You'll see that clearly before you leave, so you can decide whether to wait, invite someone directly, or choose a different time or route. Sports HQ can't guarantee that someone will always be free to join you." }}

{{ sg.faq4_q | default: "Can a friend cycle beside me instead of running?" }}

{{ sg.faq4_a | default: "Yes. Any member of your event can confirm for a run, whether they're running alongside you or riding a bike as company and an extra set of eyes." }}

{{ sg.faq5_q | default: "Is Sports HQ an emergency or live-location safety app?" }}

{{ sg.faq5_a | default: "No. Sports HQ helps you coordinate runs with people you already trust — it doesn't provide live location tracking, emergency alerts, or a guarantee of personal safety. Use a dedicated safety app or service alongside it if you need those features." }}
