For Ad-Hoc Run Clubs

Less Texting. More Running.

Your run club doesn't run on a fixed schedule — it runs on whoever's free this evening. Sports HQ replaces the never-ending group chat with instant notifications and one-tap confirmations, so you spend less time coordinating and more time on the road.

This is for you if: you organise a run club, a training crew, or any group activity that gets proposed last-minute rather than scheduled weeks in advance — and you're sick of typing "who's in tonight?" into a group chat.

Centralised Communication

One event, one crew, zero noise

Create your run club as an event in Sports HQ once, and add your crew. From then on, every activity, update, and reminder flows through the app — not through three different message threads.

  • Set it up once; reuse it for every future run
  • Works just as well for any sport or activity, not just running
  • Add members with a link dropped into the group chat, or a QR code on a sign-up sheet — whichever's easier
Instant Notifications

Propose tonight's run, notify everyone instantly

Any member can create an activity instance for the crew — propose a date, time, and route, and every member gets a push notification immediately. No admin bottleneck, no waiting for someone to "see" the message.

  1. 1
    Someone proposes a run

    Any member can create the activity — it doesn't have to be the organiser.

  2. 2
    Everyone is notified at once

    A push notification goes out the moment the activity is created.

  3. 3
    Replies roll in immediately

    Confirm or decline in one tap — no typing required.

Instant Confirmation

Know who's running before you leave the house

See live attendance for tonight's run — who's confirmed, who's declined, and who hasn't replied yet — without sending a single follow-up message.

  • One-tap confirm/decline removes the back-and-forth entirely
  • Minimises overhead so the crew can focus on actually training
  • The same flow works for any sport or activity managed in Sports HQ
